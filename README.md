# Мини-синхронизатор заявок

Сервис забирает заявки с `https://test.ooobs.ru/api/orders`, нормализует телефоны к `+7XXXXXXXXXX`,
отбрасывает невалидные и дедуплицирует по телефону (максимальный `amount`, при равенстве — более поздний `created_at`).

`GET /result` возвращает:

```json
{
  "clients": [{ "name": "...", "phone": "+79991234567", "email": "...", "amount": 5000 }],
  "stats": { "received": 17, "unique": 8, "duplicates_merged": 5, "invalid_dropped": 4 }
}
```

## Правила нормализации

- из номера удаляются все нецифровые символы;
- 11 цифр, начинающихся с `7` или `8` → `+7` + последние 10 цифр;
- 10 цифр (номер без кода страны) → `+7` + 10 цифр;
- всё остальное — невалидно.

## Запуск

```bash
npm start      # http://localhost:3000/result
npm test
```

Зависимостей нет, нужен Node.js 18+.

## Деплой

- **Vercel**: `npx vercel --prod` — функция `api/result.js`, `/result` переписывается на неё через `vercel.json`.
- **Render / Railway / Fly**: команда запуска `npm start`, порт берётся из `PORT`.

## Секреты

Конфигурация читается из переменных окружения (`ORDERS_URL`, опционально `ORDERS_API_TOKEN`), задаётся в панели хостинга;
`.env` в `.gitignore`, в репозитории только `.env.example`.
